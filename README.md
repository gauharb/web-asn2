# Assignment #2 

A five-page web assignment demonstrating the use of **CSS Flexbox and CSS Grid**.
Each task has its own page, and the navigation bar connects all parts of the assignment.

## Assignment Tasks

* `Task0/index.html` — Navigation Bar using Flexbox.
* `Task1/index.html` — Three equal-height cards arranged with Flexbox.
* `Task2/index.html` — Page layout using CSS Grid areas.
* `Task3/index.html` — Nine-image gallery using CSS Grid.
* `Task4/index.html` — Portfolio page combining CSS Grid and Flexbox.

## Technologies

## Task Description

### Task 0 — Navigation Bar

A header and navigation bar are created using Flexbox.
The logo and navigation links are aligned horizontally with spacing between them.

### Task 1 — Card Row

Three plant cards are displayed in a row using Flexbox.
Each card contains an image, title, description, and button.
The cards have equal height, consistent spacing, and a hover effect.

### Task 2 — Page Layout with Grid Areas

CSS Grid is used to create a page layout containing:

* Header
* Sidebar
* Main content
* Footer

Named grid areas are used to position each section.

### Task 3 — Image Gallery

A gallery containing nine plant images is created using CSS Grid.
The gallery uses multiple columns, consistent gaps, and hover effects with captions.

### Task 4 — Portfolio Page

The final page combines Flexbox and CSS Grid.

CSS Grid is used for the main page layout, while Flexbox is used for the navigation and project card content.
