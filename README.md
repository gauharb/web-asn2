# GreenLeaf — Flexbox and CSS Grid

A five-page assignment demonstrating modern CSS layout through Flexbox and CSS Grid. Each task has its own page and the navigation links connect the tasks.

## Assignment pages

- `Task0/index.html` — Flexbox navigation bar.
- `Task1/index.html` — three equal-height plant cards in a Flexbox row.
- `Task2/index.html` — page layout built with named CSS Grid areas.
- `Task3/index.html` — nine-image CSS Grid gallery with hover captions.
- `Task4/index.html` — portfolio combining Grid and Flexbox.

The root `index.html` is the landing page. Shared styles are in `style.css`.

## Run locally

Open `index.html` in a browser. No build step or framework is required. Internet access is used for the Google Font and Unsplash photographs.

## Publish on GitHub Pages

Push the repository to GitHub. Open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save. The landing page will be served from the repository root.

## Publish on Netlify

Import the repository into Netlify and set the publish directory to the project root. No build command is required.
